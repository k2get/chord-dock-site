Edition Detail

Keep the Lite workflow.
Unlock the deeper tools in Extended.

Chord Dock Extended adds reharmonization, generation, and deeper editing without asking you to relearn the core timeline workflow. It is the upgrade for users who already like the basic flow and want to take it further.

Buy Extended License

Lite and Extended use the same installer. After purchase, enter the issued license key to unlock the extra features. The license can be used on up to 2 devices per account.

What Extended Adds

For Lite Users
Reharmonization that lets you compare options before changing the progression
Arpeggio / Bassline generation from selected sections
Tensions, slash chords, and expanded Circle of Fifths tools
Finer Snap / Length editing plus theme-side customization

Who it fits

You can build progressions, but need stronger development tools

Extended fits when Lite already feels right, but your next bottleneck is finding better variations and movement.

You want note material from the progression itself

It is built for users who want to turn a chosen section directly into Arpeggio or Bassline ideas.

You need more harmonic vocabulary and finer control

Tensions, slash chords, and finer timing controls make more sense once you are already committed to the core workflow.

Features unlocked in Extended

Reharmonize

Generate

What changes from Lite

What stays the same

  • Timeline-based chord progression editing
  • Arrangement structure with Sections and Focus Edit
  • MIDI drag export
  • Saving and reusing progression data

What gets added

  • Reharmonization comparison and application
  • Arpeggio / Bassline generation
  • Tensions, slash chords, and extra harmony tools
  • Deeper edit controls and personalization features

Install and activate

1

Install Lite

Lite and Extended share the same installer. Start by making sure Lite runs correctly in your setup.

2

Purchase the license

After purchase, you receive a license key. Each account can activate up to 2 devices.

3

Unlock it in the plugin

Open the settings menu in the plugin, enter the license, then approve the device in your browser.

For the step-by-step screen flow, use the activation section on the main page and the FAQ there.
