Arranger Mode Demo (Lite / Extended)

Open Arranger Mode and try the Setup / Performance / Song pages with limits — 90 seconds of actual playback total, Pads 1–3 only per part (Pads 4–8 shown but locked), and no Arranger MIDI export. Remaining demo time is not saved with the project and resets to 90 seconds when the project is reopened. Performance / Full Bundle removes all limits.
