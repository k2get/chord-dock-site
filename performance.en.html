What you can do with Performance

Arranger Mode — build four parts per section

Create patterns for Drums / Bass / Arp / Chord Pad per section and assign them to pads (8 pads × 2 pattern sets per part). Role-based patterns follow chord changes automatically, and per-part style presets plus random generation get you a solid starting point fast.

Dedicated pattern editors per part

Drums uses a lane-based step editor (GM defaults, remappable). Bass offers two ways to edit — a Chord-Role Sequencer and a full MIDI Roll — while Arp / Chord Pad use role-lane editing. Every pattern can be dragged out as MIDI.

Section Launcher and reservation-based switching

Queue sections with a click, number keys 1–8, or MIDI notes. Sections switch with Launch Quantize (Next Bar / Section End); pads have their own switch timing (Next Bar / Pattern End) and playback position (Bar Lock / Restart). Auto Advance and Standby Pad 1 are included, and Sync Mode (Host / Plugin) lets you follow the DAW timeline or let Chord Dock lead.

Performance page — focus on playing with 32 pads

A dedicated performing view with all 4 parts × 8 pads (32 pads) on one screen. Queue sections while shaping the arrangement with pad combinations — for live sets and structure experiments alike.

Song page — lay patterns out and hear the whole song

Arrange pad patterns along the song order and check the song end to end — with internal playback while the DAW is stopped, or following host playback. Clip editing is fully undoable.

ChordPart — every part to its own track, any instrument

Drop the bundled ChordPart plugin (VST3) on a receiving track and it connects to the main plugin automatically — no wiring. Assign any instrument per part, regardless of how your host routes plugin MIDI. Added latency is constant, at most one audio buffer (128–256 samples recommended).

Who it's for

Running accompaniment live

The Section Launcher and reservation-based switching move you safely to the next section, right on the bar.

Sketching structure with pads

Even while the DAW loops a short region, Plugin sync lets pad actions advance the song — ideal for arrangement experiments.

One instrument per part

ChordPart sends each part to its own track, so every part can use any instrument — including your DAW's built-in ones.

Demo vs. Performance

What the demo (Lite / Extended) allows

  • Open the Setup / Performance / Song pages
  • 90 seconds of actual playback in total
  • Pads 1–3 per part (Pads 4–8 visible only)
  • No Arranger MIDI export

What Performance unlocks

  • Unlimited playback time
  • All 8 pads × 2 pattern sets per part
  • Arranger pattern MIDI drag / export
  • Per-part MIDI output via ChordPart

Install and activate

1

Install Lite

All editions share the same installer, which also installs ChordPart alongside the main plugin. Confirm it launches in your usual environment.

2

Buy a license

You receive a license key after purchase. Each license covers up to 2 devices per account.

3

Activate in the plugin

Enter the key from the settings menu in the top-right of the plugin, approve the device in your browser, and the Performance features unlock.

ChordPart has no license controls of its own — it follows the main plugin's edition. Keep the main plugin and ChordPart at the same version. For an illustrated walkthrough, see the activation guide on the home page and the FAQ.
