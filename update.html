リリースノート Release notes

ChordDock v2.0.1

2026-07-14
  • ドラムパターン再生で、ループ境界やセクション境界の直後に1拍目のキックなどが重なって発音する場合がある問題を修正しました。境界ちょうどの発音は維持しています。 Fixed a drum playback issue where first-beat kicks or other drum hits could be retriggered immediately after loop or section boundaries. Hits placed exactly on the boundary are preserved.
  • Progression メニューから「印刷用コード譜を開く…」を実行できるようにしました。 Added "Open Printable Chord Sheet..." to the Progression menu.

ChordDock v2.0

2026-07
  • Performance エディションの中心機能として Arranger Mode を追加しました。セクションごとに Drums / Bass / Arp / Chord Pad の4パートを組み、パッドで演奏・予約切り替えできます。 Added Arranger Mode, the core Performance edition feature. Build four-part accompaniment per section and perform or queue it with pads.
  • Performance Page と Song Page を追加しました。4パートのパッドを一覧しながら演奏したり、曲順にパターンを配置して確認できます。 Added Performance Page and Song Page for focused pad performance and song-order pattern layout.
  • Drums のステップ編集、Bass の Chord-Role Sequencer / MIDI Roll、 Arp / Chord Pad のロールベース編集に対応しました。 Added dedicated pattern editors: Drums step editing, Bass Chord-Role Sequencer / MIDI Roll, and role-based Arp / Chord Pad editing.
  • 同梱プラグイン ChordPart を追加しました。DAW 側で MIDI チャンネル分割が難しい場合でも、パート別 MIDI を別トラックへ受け渡せます。 Added the bundled ChordPart receiver plugin, which sends per-part MIDI to separate DAW tracks even in hosts that cannot split plugin MIDI output by channel.
  • Lite / Extended でも Arranger Mode Demo を試せます。Performance または Full Bundle では全パッドと Arranger MIDI 書き出しが利用できます。 Lite and Extended can try Arranger Mode Demo. Performance or Full Bundle unlocks all pads and Arranger MIDI export.

ChordDock v1.5.3

  • 9thコードまわりのバグを修正しました。 Fixed a bug related to 9th chords.

ライセンスと認証 License & activation

ChordDock v2.0.1 は、同じパッケージ内で Lite / Extended / Performance の機能をライセンス状態に応じて切り替えます。 ChordDock v2.0.1 uses one package, and your license state switches between Lite / Extended / Performance features.

  • ご購入時に発行されたシリアルキーを、プラグイン内の認証画面で入力してください。 Enter the serial key you received at purchase in the plugin’s activation screen.
  • 1 ライセンスにつき、2台までアクティベーションできます。 Each license can be activated on up to 2 machines.
  • ChordPart 自体にはライセンス操作はありません。メインの Chord Dock 側のエディション状態に従います。 ChordPart has no separate license operation. It follows the edition state of the main Chord Dock plugin.
  • PC の買い替えや OS 再インストール時には、必要に応じて旧環境のライセンス解除を行ってください。 Before replacing a PC or reinstalling the OS, deactivate the old environment if needed.

FAQ / トラブルシューティング（アップデート） FAQ / Troubleshooting (Updates)

アップデート時によくある質問を抜粋しています。詳しい操作手順は、v2.0.1 パッケージ同梱のユーザーマニュアルをご確認ください。 This section covers update-related questions. For detailed operation steps, see the user manual included in the v2.0.1 package.

Q1. v1.5 から v2.0 で何が増えましたか？ Q1. What is new from v1.5 to v2.0?

v2.0 では、コード進行をもとに伴奏パターンを組んで演奏する Arranger Mode、4パートを一覧できる Performance Page、曲順に配置できる Song Page、パート別 MIDI 受信用の ChordPart が追加されました。 v2.0 adds Arranger Mode, Performance Page, Song Page, and the bundled ChordPart receiver for per-part MIDI routing.

従来のタイムライン編集、セクション、Arpeggio / Bassline、 Reharmo、MIDI ドラッグ書き出しのワークフローも引き続き利用できます。 Existing timeline editing, sections, Arpeggio / Bassline, Reharmo, and MIDI drag workflows remain available.

Q2. Windows 版はどう更新すればよいですか？ Q2. How should I update the Windows version?

DAW を終了してから ZIP を展開し、Chord Dock.vst3 と ChordPart.vst3 の両方を VST3 フォルダへコピーしてください。 Quit your DAW, unzip the package, and copy both Chord Dock.vst3 and ChordPart.vst3 into your VST3 folder.

メインプラグインと ChordPart のバージョンが違うと、ChordPart は安全のため送受信を停止します。必ず同じ v2.0.1 の組み合わせで更新してください。 If the main plugin and ChordPart versions differ, ChordPart stops for safety. Update both as a matching v2.0.1 set.

Q3. macOS 版はどう更新すればよいですか？ Q3. How should I update the macOS version?

DAW を終了してから macOS インストーラーを実行してください。更新後に DAW 側で見つからない場合は、プラグイン再スキャンを実行してください。 Quit your DAW, run the macOS installer, and rescan plugin folders in your DAW if the updated plugins do not appear.

Q4. アップデート後に DAW にプラグインが表示されません Q4. After updating, the plugin does not appear in my DAW

次の点をご確認ください： Please check the following:

  • インストールまたはコピーが正常に完了しているか Whether installation or file copying completed successfully
  • Windows の場合、.vst3 ファイルが標準の VST3 フォルダにあるか On Windows, whether the .vst3 files are in the standard VST3 folder
  • DAW のプラグイン再スキャンと再起動 Rescanning plugin folders and restarting the DAW
Q5. アップデート前のプロジェクトとの互換性は大丈夫ですか？ Q5. Will my existing projects remain compatible after updating?

Chord Dock の状態は基本的に DAW プロジェクトと一緒に復元されます。v2.0 では、Arranger のパターン、パッド割り当て、Song Page の配置、ChordPart の設定もプロジェクトに保存・復元されます。 Chord Dock state is generally restored with the DAW project. In v2.0, Arranger patterns, pad assignments, Song Page layout, and ChordPart settings are also saved and recalled.

ただし、更新後に DAW のキャッシュの影響で表示や認識が不安定な場合は、プラグイン再スキャンを行ってください。 If your DAW cache causes recognition issues after updating, run a plugin rescan.

Q6. Lite / Extended のままでも Arranger Mode を試せますか？ Q6. Can I try Arranger Mode with Lite or Extended?

はい。Lite / Extended でも Arranger Mode Demo として基本操作を試せます。実再生時間は合計90秒、各パート Pad 1〜3まで、Arranger MIDI 書き出しは利用できません。 Yes. Lite and Extended can try Arranger Mode Demo. Demo playback is capped at 90 seconds total, each part can use Pad 1-3, and Arranger MIDI export is unavailable.

全パッドと Arranger MIDI 書き出しを使うには、Performance または Full Bundle が必要です。 Performance or Full Bundle is required for all pads and Arranger MIDI export.

Q7. アップデートしたら Lite になってしまいました Q7. After updating, it shows as Lite

ライセンス情報が失われた場合は、プラグイン内の認証画面でシリアルキーを入力し、オンライン認証を実行してください。 If license information was lost, enter your serial key in the plugin activation screen and complete online activation.

ChordPart 側ではライセンス入力は不要です。メインの Chord Dock 側の認証状態に従います。 ChordPart does not require license entry. It follows the activation state of the main Chord Dock plugin.

Q8. ChordPart が接続されない、または Version mismatch と表示されます Q8. ChordPart is not connected or shows Version mismatch

次の点をご確認ください： Please check the following:

  • Chord Dock 本体と ChordPart が同じ DAW プロジェクト内に読み込まれているか Whether the main Chord Dock plugin and ChordPart are loaded in the same DAW project
  • メインプラグイン側の Part Send がオンになっているか Whether Part Send is enabled on the main plugin
  • Chord Dock 本体と ChordPart が同じ v2.0.1 の組み合わせになっているか Whether the main plugin and ChordPart are both v2.0.1
Q9. 詳しい手順を確認したい Q9. Where can I find detailed instructions?

v2.0.1 パッケージに同梱されているユーザーマニュアルをご確認ください。Arranger Mode、Performance Page、Song Page、ChordPart の設定手順までまとまっています。 See the user manual included in the v2.0.1 package. It covers Arranger Mode, Performance Page, Song Page, and ChordPart setup steps.
